# 🤖 Advanced Preference Prediction using BERT and Chatbot Arena Data

## 📌 Project Overview
This project focuses on predicting user preferences in chatbot interactions using the **Chatbot Arena dataset**. By fine-tuning a pre-trained BERT model, we aim to forecast which response a user will prefer among two generated by different chatbot models. The work tackles key challenges like **bias mitigation**, **class imbalance**, and **contextual variability**, contributing toward building more fair and user-centric conversational AI systems.

## 🎯 Objectives
- Fine-tune BERT to classify user preference in chatbot responses.
- Mitigate biases such as verbosity and positional bias.
- Handle class imbalance using weights and preprocessing strategies.
- Evaluate the model using accuracy, precision, recall, and F1 score.

## 📁 Dataset
- **Name**: [Chatbot Arena Dataset](https://www.kaggle.com/competitions/llm-classification-finetuning/overview)
- **Labels**: 
  - `Winner Model A`  
  - `Winner Model B`  
  - `Tie`

## 🧪 Methodology
### 1. Preprocessing
- Lowercasing, punctuation/special character removal
- Tokenization using `bert-base-uncased` (HuggingFace)
- Sequence padding/truncation to 512 tokens

### 2. Class Balancing
- Computed class weights using `sklearn`
- Addressed imbalance (e.g., underrepresented `tie` class)

### 3. Model Setup
- Pre-trained: `bert-base-uncased`
- Fine-tuned with classification head (3-class)
- Early stopping and learning rate: `1e-5`

### 4. Training Configuration
- Train/Test split: 90/10
- Epochs: 4
- Batch Size: 16 (train), 32 (eval)
- Loss Function: Weighted Cross-Entropy

### 5. Techniques Used
- Multi-task learning
- Adversarial training to reduce bias

## ⚙️ Experimental Environment
- **Hardware**: Intel Core i7, NVIDIA Tesla T4 GPU, 16 GB RAM
- **Software**: Python 3.8, PyTorch, Transformers (HuggingFace), Scikit-learn, NumPy, Pandas, Matplotlib

## 📊 Results
| Metric     | Value      |
|------------|------------|
| Accuracy   | 69.5%      |

| Validation Loss | 0.6917 |

- Balanced predictions between `winner_model_a` and `winner_model_b`
